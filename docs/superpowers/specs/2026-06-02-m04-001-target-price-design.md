## 1. 목적

프로젝트별·어셈블리별로 Part의 목표가를 입력·저장하고, 저장 시마다 버전을 자동 누적(v01→v02→…)한다. 과거 버전 선택 시 그리드는 read-only로 전환된다.

## 3. 상단 폼 상세

### 3-1. 필드 정의

| 필드 | 타입 | 너비 | 비고 |
|------|------|------|------|
| 프로젝트 * | select | 220px | MockData.seed.projects 목록 |
| 어셈블리 * | select | 200px | 프로젝트 선택 시 어셈블리 필터 |
| 버전 | select | 100px | v01~vNN 목록, 기본값: 최신 버전 |
| 저장일시 | readonly | 160px | 선택된 버전의 저장 일시 |
| 작성자 | readonly | 100px | 선택된 버전의 작성자 |

### 3-2. 액션 버튼

| 버튼 | 클래스 | 위치 | 동작 |
|------|--------|------|------|
| 저장 | btn-solid-blue | 우측 | 현재 그리드 목표가를 저장, 버전 +1 |
| 취소 | btn-white | 우측 | 마지막 저장 상태로 롤백 |
| 엑셀 | btn-white | 우측 | 그리드 데이터 다운로드 |

### 3-3. 버전 상태 규칙

- **최신 버전 선택 시**: 목표가 셀 편집 가능, 저장/취소 버튼 활성
- **과거 버전 선택 시**: 그리드 전체 read-only, 저장/취소 버튼 비활성, 상단에 "이전 버전 조회 중" 경고 배너 표시

## 4. 그리드 상세

### 4-1. 필터 바

- Search (400px, placeholder: "Search")
- 필터 드롭다운: 소재 구분 (전체/강판/HDPE/Al/CFRP)
- Gap 상태 드롭다운: 전체/Gap 내/Gap 초과/미입력
- 우측: 총 N건 카운트 + Gap 요약 (초과 N건 강조)

### 4-2. 컬럼 정의

| # | 컬럼명 | 정렬 | 너비 | 비고 |
|---|--------|------|------|------|
| 1 | No | center | 40px | 행번호 |
| 2 | Part No | left | 110px | ss-col-link |
| 3 | Part명 | left | 180px | ss-col-default |
| 4 | 소재 | center | 80px | 소재 태그 배지 |
| 5 | 중량(g) | right | 80px | ss-col-default |
| 6 | 계산원가 | right | 100px | ss-col-default, 천단위 구분 |
| 7 | **목표가** | right | 110px | **editable input**, 최신버전만 |
| 8 | Gap 금액 | right | 90px | 계산원가-목표가, 자동계산 |
| 9 | Gap % | center | 70px | (Gap금액/계산원가)×100, 색상 조건부 |
| 10 | 상태 | center | 80px | 확정/Gap초과/미입력/RFQ중 |

### 4-3. 조건부 색상

- Gap % ≤ 0 (목표가 ≥ 계산원가): `ss-col-green`
- Gap % 1~10: `ss-col-default`
- Gap % > 10: `ss-col-red` + 행 배경 #FAEAEA 연하게
- 목표가 미입력: 상태 셀 "미입력" + 회색 처리

### 4-4. 소재 태그

- SPFC/SPFH → `.mat-spfc` / `.mat-spfh`
- HDPE → `.mat-hdpe`
- Al → `.mat-al`
- CFRP → `.mat-cfrp`
- 기타 → `.mat-spfc` (기본)

## 5. 버전 관리 로직 (프론트 시뮬레이션)

```
versions = [
  { ver: "v01", date: "2025-10-15 14:32", author: "김구매", parts: [...] },
  { ver: "v02", date: "2025-11-20 09:05", author: "이소싱", parts: [...] },
  { ver: "v03", date: "2025-12-04 11:48", author: "김구매", parts: [...] },  ← 최신
]
```

- 저장 클릭 → `v0(N+1)` 생성, 버전 select에 추가, 최신버전으로 자동 이동
- 버전 select 변경 → 해당 버전 parts 데이터 그리드에 렌더링
